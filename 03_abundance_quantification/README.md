# Step 3: Quantification of EV DNA Abundance

This directory is organized by task. Each task has:
- `input_data/` for task inputs
- `output_data/` for task outputs
- `script/` for task scripts

## Folder Structure

- `task_01_fpkm/`
  - `input_data/region_for_fpkm/`       — BED regions for coverage counting
  - `output_data/coverage_count/`        — Raw BEDtools coverage counts per feature
  - `output_data/fpkm_out/`              — Per-feature FPKM CSV files (including `gene_fpkm.csv`, `gene_mt_fpkm.csv`)
  - `script/run_bedtools_coverage.sh`    — Runs BEDtools coverage for all feature types
  - `script/calculate_fpkm.py`           — Computes FPKM from coverage counts

- `task_02_high_expression/`
  - `input_data/`                        — Place `srr5658399_count_with_length.xlsx` here (or in `data/`)
  - `output_data/`
    - `merged_CPM_table.csv`                       — Merged EV + SRR CPM/FPKM table
    - `gene_99thpercentile_high_abundance.csv`     — **EV-only top 1% expressed genes** (auto-generated by `merge_file.py`)
    - `gene_srr_99thpercentile_high_abundance.csv` — **SRR-only top 1% expressed genes** (auto-generated by `merge_file.py`)
    - `intersect_genes.csv`                        — Genes in both EV and SRR top-1% lists
    - `intersect_genes_with_names.csv`             — Intersect genes with SGD annotations
  - `script/merge_file.py`              — Merges EV + SRR data, computes CPM/FPKM, labels and writes top 1% files
  - `script/correlation_test.py`        — Spearman correlation between EV-seq and RNA-seq CPM
  - `script/intersect_genes.py`         — Intersects the two top-1% gene lists; supports default paths (no args needed)

- `task_03_gene_annotation/`
  - `input_data/`
  - `output_data/gene_mt_fpkm_w_name.csv` — Mitochondrial gene FPKM with SGD gene names
  - `script/sgd_lookup.py`               — Queries SGD REST API for gene names and descriptions

- `script/run_pipeline.sh`              — Runs all tasks in order (steps 1–6)

## Usage

Run the full pipeline:

```bash
bash script/run_pipeline.sh
```

Run tasks individually:

```bash
# Task 1: BEDtools coverage + FPKM
bash task_01_fpkm/script/run_bedtools_coverage.sh
python3 task_01_fpkm/script/calculate_fpkm.py

# Task 2: merge EV + SRR, compute CPM/FPKM, write top-1% files
python3 task_02_high_expression/script/merge_file.py
# Output: merged_CPM_table.csv, gene_99thpercentile_high_abundance.csv, gene_srr_99thpercentile_high_abundance.csv

# Task 2: Spearman correlation
python3 task_02_high_expression/script/correlation_test.py

# Task 2: intersect EV and SRR top-1% gene lists
# Default (uses output_data paths automatically — no arguments needed):
python3 task_02_high_expression/script/intersect_genes.py

# Or with explicit paths:
python3 task_02_high_expression/script/intersect_genes.py \
  task_02_high_expression/output_data/gene_99thpercentile_high_abundance.csv \
  task_02_high_expression/output_data/gene_srr_99thpercentile_high_abundance.csv \
  task_02_high_expression/output_data/intersect_genes.csv \
  gene_id Gene

# Task 3: SGD gene annotation
python3 task_03_gene_annotation/script/sgd_lookup.py
# Optional: annotate a custom gene list
python3 task_03_gene_annotation/script/sgd_lookup.py -i <input.csv> -o <output.csv> -c <gene_column>
```
